# Real Geology mineral identity catalogue

Real Geology owns **Overworld placement**, while installed mods continue to own machines, recipes, and processing. The block ID and `c:ores/<material>` tag remain compatible with the industrial material; the in-game name says what is actually in the rock.

| Compatible material | Geological form generated | Main setting |
|---|---|---|
| Coal / lignite | coal and lignite seams | wet sedimentary shale beds |
| Iron | hematite/magnetite iron formation | folded, old metamorphic formation |
| Copper | copper sulphides | porphyry stockwork and hydrothermal fissures |
| Gold | native gold | porphyry core and deep hydrothermal veins |
| Zinc | sphalerite | carbonate and clastic Pb-Zn districts |
| Lead | galena (lead sulphide) | carbonate replacement and sulphide districts |
| Tin | cassiterite | granite and pegmatite |
| Lithium | spodumene | pegmatite |
| Uranium | uraninite | deep granite and pegmatite |
| Nickel | pentlandite | mafic/ultramafic cumulate lenses |
| Osmium | platinum-group-element bearing ore | extremely rare nickel-bearing mafic lens byproduct |
| Silver | acanthite/native silver association | sulphide districts and fissures |
| Fluorite | fluorite | carbonate-hosted mineral zones |
| Sulfur | native sulfur | volcanic/hydrothermal zones |
| Bauxite | aluminium ore rock | hot, wet, shallow lateritic blanket |
| Saltpeter | nitrate mineral proxy | rare dry-basin evaporitic zone |
| Diamond | diamond in kimberlite | sparse deep mantle-derived pipe |
| Lapis | lazurite-bearing lapis lazuli | rare metamorphosed carbonate band |
| Emerald | beryl-bearing occurrence | rare pegmatite/contact zone |
| Redstone | fictional crystal resource | rare deep volcanic/hydrothermal gameplay mineral |

Ruby and sapphire are real corundum minerals, but this modpack does not currently contain a compatible ruby/sapphire material chain. They are therefore **not** generated as misleading decorative ores. They can be added later only alongside proper mining, processing, and use recipes.

The shared `c:` tags preserve cross-mod recipe compatibility. This is intentionally an Overworld system; Nether and End generation remain separate for now.
